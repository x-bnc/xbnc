# xBNC 1.0.0 documentation

The same documentation, with search and in several languages, is published as the xBNC wiki, a website of its own that anyone can read without installing xBNC. The Spanish documentation is in [es/README.md](es/README.md). The guide for translators is [TRANSLATING.md](../TRANSLATING.md) and the list of changes is [CHANGELOG.md](../CHANGELOG.md).

| File | What it covers |
| --- | --- |
| [OVERVIEW.md](OVERVIEW.md) | **What xBNC is.** What xBNC does and how it works. |
| [INSTALL.md](INSTALL.md) | **Installation and first steps.** Installing xBNC on a server and the first minutes after. |
| [CLIENTS.md](CLIENTS.md) | **Connecting your IRC client.** HexChat, mIRC, WeeChat, irssi, mobile apps and others. |
| [NETWORKS.md](NETWORKS.md) | **Networks.** Adding IRC networks, servers, services login and identities. |
| [COMMANDS.md](COMMANDS.md) | **IRC commands.** Every `/msg *status` command. |
| [PANEL.md](PANEL.md) | **Web panel, history and notifications.** The web panel, the history search and the notifications. |
| [MODULES.md](MODULES.md) | **Modules.** The 24 native modules and their settings. |
| [PLUGINS.md](PLUGINS.md) | **Plugins.** The 18 official plugins and how to write new ones. |
| [USERS_AND_SECURITY.md](USERS_AND_SECURITY.md) | **Users, roles and security.** Roles, quotas, two-step verification, passkeys, SSO and protections. |
| [CONFIGURATION.md](CONFIGURATION.md) | **Configuration (xbnc.toml).** Every setting of the configuration file. |
| [ADMINISTRATION.md](ADMINISTRATION.md) | **Administration.** Command line, alerts, monitoring and updates. |
| [DATA.md](DATA.md) | **Backups, databases and migration.** SQLite and PostgreSQL, backups, high availability and migration from another bouncer. |
| [API.md](API.md) | **REST API.** Every route of the REST API (the specification is in `openapi.json`). |
| [TRANSLATIONS.md](TRANSLATIONS.md) | **Translating xBNC.** Language files of the panel and of IRC (the full guide is `../TRANSLATING.md`). |
| [IRCV3.md](IRCV3.md) | **IRCv3.** The IRCv3 capabilities supported with servers and with clients. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | **Architecture.** How the code is organised. |
| [THREAT_MODEL.md](THREAT_MODEL.md) | **Threat model.** What xBNC protects, against whom and how. |
| [PERFORMANCE.md](PERFORMANCE.md) | **Performance.** Measurements and limits. |
| [TESTING.md](TESTING.md) | **Testing.** Test environment, automatic tests, the test report and how to test the beta. |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | **Common problems.** Symptoms, causes and solutions. |
| [STATUS.md](STATUS.md) | **Status of this version.** What is included, how it was checked and the known limits. |
| [openapi.json](openapi.json) | **OpenAPI specification.** The REST API as OpenAPI 3.1. |
