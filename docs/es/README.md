# Documentación de xBNC 1.0.0

La misma documentación, con buscador y en varios idiomas, está publicada como la wiki de xBNC, una web aparte que cualquiera puede leer sin instalar xBNC. La documentación en inglés está en [../README.md](../README.md), la guía para traductores es [TRANSLATING.md](../../TRANSLATING.md) y la lista de cambios es [CHANGELOG.md](../../CHANGELOG.md).

| [PANEL.md](PANEL.md) | **Panel web, historial y avisos.** El panel web, la búsqueda en el historial y los avisos. |
| [MODULES.md](MODULES.md) | **Módulos.** Los 24 módulos nativos y sus ajustes. |
